# Why (we still need) linear regression — a deep-dive for applied and data scientists

*简体中文说明见 [README_cn.md](README_cn.md)。*

A first-principles tutorial arguing that **two hundred years on, the straight line is still the honest starting point of data analysis**.

**Authors:** Haoyi Xiong (熊昊一), Lingkai Kong (孔令凯)

## What's inside

Not a formula-catalogue textbook, but a deep walk "from estimate to inference," starting from a one-dimensional line:

| Ch. | Content |
| --- | --- |
| Preface | Audience, origins, the scholars who shaped the book, AI-assisted-writing disclosure |
| 1 | Introduction: why the straight line is still the honest starting point |
| 2 | One-dimensional regression: correlation from the regression viewpoint; direction and causation from the variance viewpoint |
| 3 | High dimensions ($n \gg d$): the closed-form least-squares world, $\widehat\beta=(X^\top X)^{-1}X^\top y$ |
| 4 | Gradient descent: iteration, fixed points, and the exact solution of $\widehat\beta_t$ in $t$, $X$, $y$ |
| 5 | The other fixed point ($d>n$): the minimum-norm solution $\widehat\beta'=X^\top(XX^\top)^{-1}y$, and its relation to the pseudoinverse |
| 6 | From estimation to inference: covariance/precision matrices, conditional independence, lasso / elastic net / CLIME / graphical lasso, debiased lasso |
| 7 | Inference at scale: from sparsity to false discovery rate control (BH, knockoffs) |
| 8 | Nonlinear latent spaces: linear regression as a natural kernel method — random Fourier features and the neural tangent kernel as bridges to deep networks |
| 9 | Epilogue: so, why linear regression? |
| — | Complete solutions to all exercises |

Intended for applied and data scientists with a working knowledge of linear algebra and calculus. The theory is deliberately not measure-theoretic: specialists in mathematical statistics will find it informal; everyone else is invited to read it cover to cover.

## A note on how this book was written

The text was produced by Moonshot AI's **Kimi K2.8** model running in the **Kimi Work desktop** agent mode — it wrote the LaTeX source directly, compiled the PDF, rendered and inspected pages, and proofread chapter by chapter. The human expert (Haoyi Xiong) supplied the outline, the chapter content, and his own multi-year thinking about linear regression — in particular the points he had personally worked on: the exact gradient-descent solution in the underdetermined case, the kernel-methods view under latent projections, and the precision-matrix–conditional-independence connection. *The human decides what to ask and what to believe; the machine does the writing and the checking.*

The preface honors the seven scholars whose work shaped the book: **Francis Bach** (first-principles learning theory — the kernel perspective of Ch. 8 and the optimization–statistics interlocking of Ch. 4–5), **Ryan Tibshirani** (computable, auditable methodology — the estimate-to-inference route of Ch. 6), **Jingfeng Wu** ("gradient descent dominates ridge regression" — the frontier of the iteration-as-regularization story), **Arthur Jacot** (the neural tangent kernel — the linear-regression → kernel → deep-networks road of Ch. 8), **Jianqing Fan** (high-dimensional statistical frameworks — the Ch. 6 roadmap), **David Donoho** (compressed sensing — sparsity makes estimation possible), and **Emmanuel Candès** (FDR control and knockoffs — symmetry makes inference credible).
